# 3D-Viewer

https://stepastepa.github.io/3D-Viewer/

Hotkeys:
- Press 1 (Translate), 2 (Rotate), 3 (Scale).
- Press X to change Display Mode.

Navigation (Perspective):
- Right Click Drag: Orbits the camera.
- Shift + Right Click Drag: Pans the camera.
- Left Click Drag: "Looks" around (First-Person interpretation).
- WASD + QE: Fly around.

Drag & Drop feature:
- Drag the .obj file from your file explorer and drop it into the viewer window.
- The model should appear in the scene (usually at 0,0,0).
