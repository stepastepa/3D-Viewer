# 3D-Viewer

https://stepastepa.github.io/3D-Viewer/

Hotkeys:
1) Press 1 (Translate), 2 (Rotate), 3 (Scale).
2) Press X to change Display Mode.

Navigation (Perspective):
1) Right Click Drag: Orbits the camera.
2) Shift + Right Click Drag: Pans the camera.
3) Left Click Drag: "Looks" around (First-Person interpretation).
4) WASD + QE: Fly around.
